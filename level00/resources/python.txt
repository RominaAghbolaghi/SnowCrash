حالا کلِّ کد، خط به خط
python
s='cdiiddwpgswtgt'
یک متغیر (variable) به اسمِ s می‌سازه و رشته‌ی رمزشده رو توش می‌ذاره.
python
for n in range(1,26):
یک حلقه. range(1,26) یعنی عددهای ۱ تا ۲۵ (عددِ آخر، ۲۶، شامل نمی‌شه). پس n می‌چرخه ۱، ۲، ۳ ... ۲۵.
یعنی همه‌ی چرخش‌های ممکنِ ROT رو امتحان می‌کنیم.
python
    print(n, ''.join(chr((ord(c)-97+n)%26+97) for c in s))

این خطِ اصلیه. از داخل به بیرون بازش می‌کنم:

for c in s → روی هر حرفِ رشته (c) یکی‌یکی می‌ره. (c = character)
ord(c) → حرف رو به عددِ کدِ ASCII تبدیل می‌کنه. مثلاً a=97، b=98 ... z=122.
-97 → عدد رو میاره به بازه‌ی ۰ تا ۲۵. (یعنی a=0، b=1 ... z=25). این کار محاسبه رو راحت می‌کنه.
+n → حالا n تا جلو می‌بریمش = همون چرخش.
%26 → باقیمانده بر ۲۶. اگه از z رد شدیم، از اولِ الفبا بچرخه. (این همون سؤالِ modulo‌ئه که ازت پرسیدم!)
+97 → برمی‌گردونیمش به بازه‌ی واقعیِ کدِ حروف (۹۷ به بالا).
chr(...) → عدد رو دوباره به حرف تبدیل می‌کنه. (برعکسِ ord)
''.join(...) → همه‌ی حرف‌های تبدیل‌شده رو به هم می‌چسبونه و یک رشته می‌سازه.
print(n, ...) → عددِ چرخش و نتیجه‌ش رو کنارِ هم چاپ می‌کنه.
