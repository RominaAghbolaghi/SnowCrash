۱. Encodingهای مهم
1. Base64
بسیار رایج
داده را با استفاده از ۶۴ کاراکتر قابل‌نمایش تبدیل می‌کند:
A-Z
a-z
0-9
+
/
نکته تشخیص:
- اغلب شامل حروف بزرگ و کوچک، اعداد و + و / است.
- ممکن است در انتهای آن = یا == ببینی.
- وجود = الزامی نیست.





2. Base32
از ۳۲ کاراکتر استفاده می‌کند:
A-Z
2-7



3. Hexadecimal (Base16)
هر Byte را با دو رقم Hex نمایش می‌دهد.

کاراکترهای مجاز:
0-9
a-f
نکته تشخیص: رشته‌ای که فقط از اعداد و حروف a-f تشکیل شده ممکن است Hex باشد، اما ممکن است Hash هم باشد. طول و ساختار به‌تنهایی کافی نیستند.




4. URL Encoding (Percent Encoding)
برای نمایش کاراکترهایی که در URL نیاز به تبدیل دارند استفاده می‌شود.

چند نمونه:
کاراکتر	Encoding
Space	%20
!	%21
@	%40
/	%2F
?	%3F








Cipher معمولاً به یک روش رمزنگاری یا تبدیل متن گفته می‌شود که هدفش پنهان کردن محتوای اصلی است.

بیاییم تفاوتشان را روشن کنیم.
۱. Encoding چیست؟
Encoding یعنی تبدیل داده از یک قالب به قالب دیگر، برای ذخیره‌سازی، انتقال یا سازگاری.


۲. Cipher چیست؟
Cipher الگوریتمی است که برای رمزگذاری و رمزگشایی داده استفاده می‌شود.

دو مفهوم مهم داریم:
- Plaintext: متن اصلی و قابل‌خواندن
- Ciphertext: متن رمزگذاری‌شده
